# Template Undangan Pernikahan Online

Template undangan umum yang siap dipasang di GitHub Pages. Pengunjung tidak perlu login dan tidak memakai nama tamu khusus.

## Cara mengunggah ke GitHub Pages

1. Masuk ke https://github.com lalu buat repository baru.
2. Beri nama, misalnya `undangan-yuspramuli-nursaidah`.
3. Pilih **Public**, kemudian klik **Create repository**.
4. Klik **Add file → Upload files**.
5. Upload seluruh isi ZIP ini. Pastikan `index.html` berada di halaman utama repository, bukan di dalam folder tambahan.
6. Klik **Commit changes**.
7. Buka **Settings → Pages**.
8. Pada **Build and deployment**, pilih **Deploy from a branch**.
9. Pilih branch **main**, folder **/(root)**, lalu klik **Save**.
10. Tunggu beberapa menit. Link akan tampil pada halaman GitHub Pages.

Contoh alamatnya:

`https://NAMA-AKUN.github.io/undangan-yuspramuli-nursaidah/`

## Mengganti isi undangan

- Nama, tanggal, dan teks acara: edit `index.html`.
- Warna dan tampilan: edit `assets/style.css`.
- Tanggal countdown: edit `assets/app.js`, pada bagian `2026-09-16T08:00:00+08:00`.
- Foto: ganti `assets/couple-reference.jpg` menggunakan nama file yang sama.

## Catatan

- Nomor rekening belum ditampilkan karena data contoh sebelumnya mengandung huruf dan perlu dikonfirmasi.
- Waktu dan lokasi masih berupa keterangan sementara.
- Musik menggunakan instrumental ringan dari browser, sehingga tidak memerlukan file lagu tambahan.
